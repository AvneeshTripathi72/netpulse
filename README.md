# NetPulse — High-Precision Internet Speed Test & Host Telemetry Portal

NetPulse is a high-performance web application built with Next.js, TypeScript, Tailwind CSS, and Supabase. It measures broadband throughput, latency, jitter, and host edge telemetry in real-time.

## 🚀 Features

- **Real-Time Speed Test Engine**: Parallel binary chunk streaming for download speed, binary byte upload testing, and multi-sample ping & jitter calculation.
- **Host & Edge Infrastructure Telemetry**: Live metrics covering host server node, transport protocol, edge region, and SSL security.
- **Analytics & History**: Persistent measurement logs with unique measurement IDs (e.g., `NP-20260914-XXXXX`).
- **User Feedback Dialog**: Instant popup feedback form linked to Supabase storage and email dispatch.
- **Micro Startup Aesthetics**: Modern, responsive layout with high-contrast elements.

## 🛠 Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Lucide Icons
- **Database**: Supabase
- **Deployment**: Vercel
